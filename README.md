

# Country Explorer

## Features
- View all countries
- Search countries
- Filter by region
- Sort countries
- View country details

## Tech Stack
- React
- React Router
- Axios
- Tailwind CSS

## Run Locally

npm install
npm run dev

## Development Note

Due to availability/deprecation issues with the original REST Countries API endpoint, an alternative country dataset was used.

## Note

The original REST Countries API endpoint mentioned in the assignment was unavailable/deprecated during development. Therefore, an alternative country dataset was used to ensure the application remains fully functional and meets the assignment requirements.

All required features including:
